# Course overview

A beginner-friendly, Python-based introduction to stellar astrophysics and H–R diagrams.

## Why this course exists

Open Astrophysics Learning is built so students can understand stellar astrophysics using **real data and Python**, not only memorization or textbook-only study.

The focus is how astronomers actually work — combining physics, data, and computation.

## What makes it different

- You **analyze data**, not only read theory  
- You follow **scientific workflows**, not isolated facts  
- Python is a **tool**, not the end goal  
- The course builds **scientific thinking**, not rote learning

## Outcomes

After completing the path you should be able to:

- Understand different types of stars  
- Explain and interpret an H–R diagram  
- Work with astronomy-style datasets  
- Plot ideas related to HR diagrams using Python  
- Approach problems with research-oriented thinking  

## Access

This course is hosted freely on GitHub Pages. Anyone with an internet connection can use it.

**Completely free · Open source · Built for students and self-learners**
